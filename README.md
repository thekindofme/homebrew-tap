# thekindofme/tap

Homebrew tap for [Margin](https://margin.yasithfernando.com), local-first AI meeting notes for macOS (Apple Silicon, macOS 14 or later).

```sh
brew install --cask thekindofme/tap/margin
```

This also installs the `margin` command-line tool. Margin updates itself; `brew upgrade --cask margin` works too.

The cask's `version` and `sha256` are updated automatically when a release is published in [thekindofme/margin](https://github.com/thekindofme/margin).
