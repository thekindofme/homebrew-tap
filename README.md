# thekindofme/tap

Homebrew tap for [Milkrice](https://milkrice.yasithfernando.com), local-first AI meeting notes for macOS (Apple Silicon, macOS 14 or later).

```sh
brew install --cask thekindofme/tap/milkrice
```

This also installs the `milkrice` command-line tool. Milkrice updates itself; `brew upgrade --cask milkrice` works too.

The cask's `version` and `sha256` are updated automatically when a release is published in [thekindofme/milkrice](https://github.com/thekindofme/milkrice).
